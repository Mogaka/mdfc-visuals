PARITY GAPS

1
Runtime Container VA (Windows) Azure only. AWS and GCP show a direct feature gap for Windows runtime image vulnerability assessment.
2
Runtime Container VA (Drift Detection) Azure only. Registry-agnostic runtime drift VA is not available in AWS or GCP.
3
Runtime Node VA Azure is GA; AWS and GCP remain in preview for Linux node assessment.
4
Runtime Node VA (Windows) Azure only. No corresponding Windows node VA coverage in AWS or GCP.
5
Control Plane Hardening Azure and GCP have GA coverage, while AWS does not.
6
Malware Detection on Nodes Azure is GA on Linux and Windows nodes; AWS and GCP remain preview-only.

Recommendation

For maximum security coverage, Azure AKS provides the most comprehensive protection. For multi-cloud deployments, all three clouds share strong parity in runtime threat detection and posture management, but Azure differentiates on runtime vulnerability assessment depth, Windows coverage, and node security maturity.

Executive takeaway

Multi-cloud customers can standardize on a broadly similar baseline across the three hyperscalers, but Azure currently offers the strongest end-to-end container security story when advanced runtime VA, Windows support, and hardened node coverage are required.
